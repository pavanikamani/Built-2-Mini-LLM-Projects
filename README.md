While these projects may look small, they represent important real-world applications of **Generative AI.**  
The goal of these projects is to understand how Large Language Models (LLMs) can simplify tasks that traditionally required complex models, rules, or extensive coding.
This repository contains two mini projects:
- 📊 Sentiment Analysis Dashboard
- 🧠 Unstructured Data Parsing
Both projects are implemented using Python and LLM APIs.

## 📊 1. Sentiment Analysis Dashboard
This project demonstrates a simple real-time sentiment analysis system built using an LLM.
In this application, a user provides a statement as input through a basic interface.  
The input text is directly sent to the LLM along with a prompt that asks the model to classify the sentiment.
The LLM analyzes the statement and returns whether the sentiment is:
- Positive  
- Negative  
- Neutral  
- Political  
The result is then displayed to the user along with a brief reasoning.
This project highlights how modern LLMs can perform sentiment analysis without requiring traditional machine learning models, datasets, or preprocessing pipelines. Instead, prompt-based interaction with an LLM is sufficient to build a working sentiment analysis system.

## 🧠 2. Unstructured Data Parsing
This project focuses on converting unstructured text into structured information using an LLM.
The user provides unstructured content such as a short paragraph containing personal or professional details.  
This input is passed to the LLM with a prompt that instructs it to extract key entities.
The LLM processes the text and generates structured output containing information such as:
- Name  
- Email  
- Phone number  
- Education  
- Skills  
- Other useful details  

Traditionally, tasks like this required writing regular expressions and custom parsing logic. In this project, the LLM handles the extraction directly, simplifying the process.
All processing happens locally within the development environment, and the extracted structured output is displayed in the terminal.
This project demonstrates how LLMs can be effectively used for information extraction and data structuring tasks.
